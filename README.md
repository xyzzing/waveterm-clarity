### Quick Install

```bash
curl -fsSL [https://raw.githubusercontent.com/xyzzing/waveterm-clarity/main/install.sh](https://raw.githubusercontent.com/xyzzing/waveterm-clarity/main/install.sh) | bash
```

### Clinical Standards

| Feature | Ergonomic Standard | Clinical Benefit |
| :--- | :--- | :--- |
| **Amber Ochre Spectrum** | 585 nm peak wavelengths | Zero short-wavelength retinal scatter; preserves contrast without glaring. |
| **Controlled Contrast** | Tuned to 6:1 - 7:1 | Completely prevents optical halation around characters. |
| **Decompressed Metrics** | 17px, 1.45x line-height, +1.2px tracking | Resolves visual crowding and character-collision blur. |
| **Medium Weight (500)** | Stroke-to-height ratio >= 1:6 | Prevents glyph stems from vanishing under astigmatic blur. |
| **Command Separators** | Horizontal rule between executions | Replaces continuous walls of text with discrete visual sessions. |
